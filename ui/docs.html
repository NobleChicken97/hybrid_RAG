Authentication

All requests to the Clinical-RAG API must be authenticated via a Bearer token. Include the token in the Authorization header.

Authorization: Bearer <YOUR_API_KEY>

POST /v1/ingest

ENDPOINT

Ingests a new clinical document into the vector space. The payload must not exceed 500MB.

Parameters

Name Type Description
file Binary The .pdf, .txt, or .md file to ingest.
chunk_size Integer The token overlap size. Default is 256.

POST /v1/ask

ENDPOINT

Submits a clinical inquiry and returns the generated synthesis along with the retrieved citation contexts. 

curl -X POST "https://api.clinical-rag.local/v1/ask" \
     -H "Authorization: Bearer TOKEN" \
     -H "Content-Type: application/json" \
     -d '{"query": "Recent guidelines for Pathway X", "mode": "hybrid"}'
